SAMIKSHYA BIRTHDAY WEBSITE
===========================

Files:
- index.html
- images/photo1.png
- images/photo2.png

How to use:
1. Extract the ZIP.
2. Keep the images folder beside index.html.
3. Double-click index.html to open the website.
4. To publish it online, upload the extracted folder to a static hosting service.

The page is fully self-contained and does not require external libraries.
